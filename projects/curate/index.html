Curate

live · open source

A private bookmark library for developers, as a Chrome and Edge extension. Save docs, repos, tools and articles from a popup, file them into collections, and find them again without digging through a bookmarks bar.

Problem

Developers find useful resources constantly and lose track of them across tabs and bookmark bars. Curate is a library that lives in the toolbar: links stay private to your account, and there is no public feed.

Architecture

popup (Manifest V3)  --Bearer JWT-->  Express API /api/v1  --->  MongoDB
chrome.storage.local                  Joi validation, JWT auth

The popup runs on a chrome-extension:// origin, so it can't use the website's session cookie. It talks to a versioned JSON API with a JWT kept in chrome.storage.local instead. The extension has no content scripts and doesn't ask for history access; it only knows about the links you choose to save.

What I built

  • The Manifest V3 extension: popup, options page and service worker, in vanilla JavaScript.
  • An Express 5 API with Joi validation and JWT auth, backed by MongoDB and Mongoose.
  • Accounts entirely in the popup: register, sign in, edit profile, change password, delete account.
  • Bookmarks with categories and tags, collections, and light and dark themes.
  • One build that ships to both the Chrome Web Store and Microsoft Edge Add-ons, plus a static landing site.

Open source

I open-sourced Curate in September 2026, a month after launch, with contributing guidelines, a code of conduct, a security policy and good-first-issue labels. It received four outside contributions in its first week.

Next

On the roadmap through January 2027: staging and safer releases, a background pipeline that extracts page text, full-text search across everything you've saved, and faster capture with a keyboard shortcut and right-click save.

Live site for Vizably↗ GitHub repository for Vizably↗
~/projects/vizably
Problem
Developers need a reliable way to find accessibility issues in websites without relying entirely on manual testing. Vizably automates the scanning and surfaces issues that can be investigated and fixed.
Decision
I designed the scanning flow with security boundaries around user-provided URLs, including SSRF protection, so the scanner can fetch external websites without exposing internal services or infrastructure.
My part
Backend architecture, automated scanning with Puppeteer and axe-core, SSRF protection, report storage, GitHub and Google integrations, authentication, and testing.
Result
My contributions helped ship the backend scanning infrastructure, security protections, integrations, authentication and automated tests, reviewed and merged through Vizably's open-source pull-request workflow.

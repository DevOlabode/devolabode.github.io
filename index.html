~/projects/voult

Voult.dev

private beta · Dec 2026

Creator · 2025 – present

Hosted authentication for Node.js. Sign-up, sessions, OAuth, MFA and passkeys run on Voult; an Express or Next.js app mounts one router and gets back to its own features.

  • Six npm packages: the SDK, Express and Next.js adapters, React hooks, a CLI and create-voult-app.
  • Sessions in httpOnly cookies: 15-minute access tokens, refresh-token rotation and reuse detection.
  • Hosted OAuth for Google, GitHub and three more providers, with provider keys encrypted server-side.
  • Node.js
  • Express
  • MongoDB
  • Redis
  • JWT
  • OAuth
  • WebAuthn

Curate

live

Creator & maintainer · 2026

A private bookmark library for developers. Save docs, repos and tools from a popup and file them into collections.

About

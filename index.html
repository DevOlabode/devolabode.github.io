Voult.dev

2025–present · Developer authentication SaaS

Authentication platform for developers, built from scratch over about a year.

Problem
Developers picking an auth provider usually trade ease of use against cost. Voult aims for Clerk-level ease of use at Supabase-level affordability.
Decision
Built it as a paid SaaS with a free tier rather than an open-source library, and split the SDK into focused npm packages: @voult/sdk, @voult/express and @voult/cli.
Built
Authentication flows, JWT access/refresh tokens, email verification, OAuth, MFA, app credentials, the SDK, API design, and developer-facing documentation.
  • JWT
  • OAuth
  • MFA
  • SDK
  • REST API
Result
Live at voult.dev. First roadmap phase completed September 2026. Private beta planned for December 2026, public launch early 2027.

Vizably

2026 · Codrlabs Solutions · Open source

Open-source accessibility scanning platform. I've contributed as a volunteer engineer at Codrlabs Solutions since early 2026.

Problem
Developers need a reliable way to identify accessibility issues in websites without relying entirely on manual testing. Vizably automates accessibility scanning and surfaces issues that can be investigated and fixed.
My part
Backend architecture, automated accessibility scanning with Puppeteer and axe-core, SSRF protection for the scanner, report storage, GitHub and Google integrations, authentication, and testing.
  • Puppeteer
  • axe-core
  • SSRF protection
  • GitHub API
  • Google API
Decision
I designed the scanning flow with security boundaries around user-provided URLs, including SSRF protection, so the scanner could fetch external websites without exposing internal services or infrastructure.
Result
My contributions helped ship the backend scanning infrastructure, security protections, integrations, authentication, and automated tests, with the work reviewed and integrated through Vizably's open-source pull-request workflow.
